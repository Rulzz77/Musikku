# MusikKu UI Update — 3 November 2026

Pembaruan ini mengikuti referensi visual player, lirik, dan halaman artis.

## Perubahan tampilan

- Player utama memakai artwork album sebagai fokus, latar gelap blur, judul/artis yang lebih jelas, seek bar minimal, tombol transport besar, dan slider volume.
- Slider volume terhubung ke kontrol volume native. Nilai disimpan saat pengguna melepas slider.
- Lirik memakai teks tanpa panel/kartu berbingkai. Baris aktif dibuat lebih terang dan besar; progres per kata hanya digunakan ketika sumber lirik menyediakan timestamp kata.
- Mini-player dan dock navigasi memakai permukaan transparan dengan blur, garis tepi tipis, dan bayangan lembut.
- Halaman artis memakai banner/foto besar, nama artis, jumlah lagu resmi, tombol Shuffle dan Putar, serta katalog lagu dengan baris datar seperti tampilan artis Spotify.
- Halaman artis tidak lagi menampilkan tab/detail playlist publik; katalog fokus pada lagu resmi artis. Daftar unggahan channel tetap dipakai sebagai sumber lagu, tanpa memuat endpoint playlist publik tambahan.
- Shuffle artis mengacak salinan urutan katalog untuk sesi putar; urutan data asli tidak diubah.

## Tema

Untuk mendapatkan nuansa rose/pink pastel seperti referensi visual, buka **Pengaturan → Tampilan → Pink pastel aesthetic**. Tema gelap/AMOLED dan tema lainnya tetap tersedia.

## Pemeriksaan

Pemeriksaan statis delimiter pada seluruh file Dart yang disentuh lolos. Flutter SDK tidak tersedia di lingkungan penyuntingan ini, sehingga `flutter analyze`, `flutter test`, dan build APK belum dijalankan. Jalankan `flutter pub get` lalu `flutter analyze` di mesin yang memiliki Flutter SDK sebelum membuat rilis.
